# svelte-contador-tareas

Lista de tareas en Svelte con stores (writable/derived) y componentes reactivos.

> Proyecto de portafolio de Luis Felipe Zuniga Leon. Desarrollado con asistencia de IA
> (generacion de codigo, revision y documentacion); el codigo fue revisado y probado manualmente.
> No declara clientes, metricas ni resultados no verificables.

## Stack

- Svelte 4
- Vite
- Stores

## Como ejecutar

```bash
npm install
npm run dev
```

## Estructura

```
src/stores.js    # estado con stores
src/App.svelte   # componente
src/main.js
```
